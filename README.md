# ProfeOS

Sitio web de ProfeOS — la app para docentes argentinos.

## Estructura

```
├── index.html              # Landing page
├── features/               # Funcionalidades
├── screenshots/            # Capturas de pantalla
├── changelog/              # Historial de cambios
├── roadmap/                # Plan de desarrollo
├── faq/                    # Preguntas frecuentes
├── privacy/                # Política de privacidad
├── terms/                  # Términos y condiciones
├── support/                # Soporte técnico
├── download.html           # Descarga de APK
├── data-deletion.html      # Instrucciones de eliminación
├── delete-account.html     # Formulario de eliminación
├── assets/
│   ├── css/styles.css      # Estilos
│   ├── js/main.js          # JavaScript
│   ├── images/             # Imágenes
│   └── favicon.svg         # Favicon
├── robots.txt
├── sitemap.xml
├── site.webmanifest
└── LICENSE
```

## Desarrollo

Abrí `index.html` en tu navegador localmente.

## Despliegue

Se despliega automáticamente a GitHub Pages al hacer push a `main`.
