# ProfeOS Website - OnlyFunPeople Studios

Official marketing website for ProfeOS school management system.

## Features

- Responsive design
- Feature showcase
- Screenshot gallery
- Download section
- Multi-language support (Spanish/English)

## Live Site

[profeos.com.ar](https://profeos.com.ar)

## Getting Started

Open `index.html` in your browser locally.

## Project Structure

```
├── index.html              # Landing page
├── features/               # Features pages
├── screenshots/            # Screenshot gallery
├── changelog/              # Release history
├── roadmap/                # Development roadmap
├── faq/                    # FAQ section
├── privacy/                # Privacy policy
├── terms/                  # Terms and conditions
├── support/                # Support page
├── download.html           # APK download page
├── assets/
│   ├── css/styles.css      # Styles
│   ├── js/main.js          # JavaScript
│   └── images/             # Images
├── robots.txt
├── sitemap.xml
└── site.webmanifest
```

## Deployment

Automatically deployed to GitHub Pages on push to `main`.
